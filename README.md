# Colorimeter Project

## Summary of Scientific Problem and Method 
The colorimeter project addresses the need for low-cost, portable detection of heavy metal contamination in water, which poses severe health risks even at trace levels. It aims to utilize 3D printing, electronics devices, and analytical chemistry techniques to create a Self-Driving Lab (SDL) that can automatically collect water samples and analyze the concentration of heavy metals, such as lead. Programming electric devices using Micropython (the RP2040 microcontroller and Adafruit AS7341 color sensor), evaluating various analytical techniques for detecting metal, and processing images using Python are the three main areas I have applied to this project. 
## Key Results and Outputs 
The Adafruit AS7341 color sensor was programmed to instruct the user to input the sample, read samples with different light intensities, and output raw and normalized data in .csv format. It has been found that the color sensor reading is more reliable in diffusion reflection (reflection on a rough surface, such as paper) than in specular reflection (reflection on a smooth surface, such as a droplet). Given that the sensor works better on rough surfaces, paper-based microfluidic devices using laser cutting were tested 1, and the devices were successful in holding 2µm of liquid within a 3mm radius circle. To complement the spectral data, a camera module is being integrated into the system, and current efforts are focused on developing image processing algorithms to extract additional colorimetric information from photographs of the samples. 
## Next Steps 
The next steps for the colorimeter project include 1) assemble the 3D hardware and the order of operation of the liquid handler, laser cutting, and image processing devices such as the color sensor and camera 2) use Bayesian optimization to evaluate the optimal parameter for the paper-based microfluidic devies 3) refine image processing techniques to analyze the concentration of the sample.
